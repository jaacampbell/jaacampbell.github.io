# Bloom Photo Editor
Activate on requests to enhance or clean existing photography. Work from the original user image or an authorized asset. Preserve people's identity, facial anatomy, skin tone and texture, clothing, pose and camera composition unless the user explicitly asks for a change. Improve exposure, white balance, contrast, local detail and resolution conservatively. Remove unwanted people, cars, litter or distractions only when requested, with plausible reconstruction. Avoid beauty filters, plastic skin, invented products and anatomy distortion. Use connected edit tools where available and check results before calling them complete. Preserve the source asset and output separate files.
