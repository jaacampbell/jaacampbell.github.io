⚡ AI Asset Sprint

An n8n automation workflow that turns a single keyword into two fully-formatted digital products in minutes — a complete ebook (with cover) and a value-enhancer bonus pack, both delivered as DOCX files.


n8n OpenAI GPT-4.1 GPT Image 1 Cloudinary ConvertAPI

What it does

Enter a topic or niche (e.g. "productivity for freelancers") into a chat trigger. The workflow fans out across three phases of AI agents and returns two download-ready DOCX files — no manual writing, no design work.

Phase 1 — Ideation

  • Uncovers 10 customer pain points
  • Generates solutions for each pain
  • Applies the $100M Offers framework to build an irresistible core offer

Phase 2 — Asset Creation

  • Generates 3 ebook title candidates, picks the best
  • Builds a 6-section content outline
  • Designs a cover image (GPT Image 1)
  • Writes the full ebook (~3,000 words)

Phase 3 — Value Stack

  • Proposes 5 high-value bonuses
  • Creates a workbook outline
  • Designs a One-Time Offer ($97–$297)
  • Delivers both DOCX links in chat

How to Build It — Step-by-Step Setup

🔵 Step 1 — Import the Workflow into n8n

  1. Open your n8n instance (cloud or self-hosted).
  2. Click + New Workflow → Import from JSON.
  3. Paste the workflow JSON (available from the author: @effortlessdigitaldon).
  4. Save the workflow.

🟠 Step 2 — Set Up OpenAI (content + images)

  1. Go to platform.openai.com/api-keys and create an account.
  2. Generate a new API key.
  3. In n8n, go to Credentials → New → OpenAI and paste your key.
  4. Assign this credential to all OpenAI nodes in the workflow.
Cost: ~$0.25 per complete run (ebook + cover image + bonus pack) using GPT-4.1 and GPT Image 1.
Note: GPT Image 1 requires identity verification on your OpenAI account to prevent misuse.

🟢 Step 3 — Set Up Cloudinary (image hosting)

  1. Sign up free at cloudinary.com.
  2. Note your Cloud Name from the dashboard.
  3. Go to Settings → Upload → Add upload preset.
  4. Set Signing Mode to Unsigned.
  5. Set Preset name to exactly: aiasset_preset
  6. Click Save.
  7. In the n8n workflow, find the Get Img Link node and replace CLOUD_NAME in the URL with your actual Cloud Name.
Cost: Free — the free plan supports thousands of image uploads per month.

🔴 Step 4 — Set Up ConvertAPI (HTML → DOCX)

  1. Sign up at convertapi.com.
  2. Find your API Secret under Authentication → Secret Key (starts with secret_).
  3. In n8n, go to Credentials → New → ConvertAPI and paste your secret.
  4. Assign this credential to both Convert eBook to DOCX and Convert Value to DOCX nodes.
Cost: Free tier = 250 conversions. Paid plans available for high-volume use.

✅ Step 5 — Activate and Test

  1. Toggle the workflow to Active.
  2. Open the chat trigger URL in your browser.
  3. Type a niche keyword, e.g. dog training for first-time owners.
  4. Wait ~2–3 minutes for all AI agents to run.
  5. You'll receive two DOCX download links in chat — done!

Tips & Troubleshooting

  • Cover image missing in DOCX: Make sure your Cloudinary upload preset is set to Unsigned and named exactly aiasset_preset.
  • JSON parse errors in Value Enhancer: GPT-4.1 occasionally wraps JSON in markdown code fences. The Build HTML (Value Enhancer) node handles this, but if it fails, check the message.content field in the node output.
  • ConvertAPI 401 errors: Your secret key may have expired. Regenerate it in your ConvertAPI dashboard.
  • Slow runs: GPT Image 1 generation takes ~30–60 seconds. The full workflow typically completes in 2–4 minutes.
  • Rate limits: If you run many workflows rapidly, OpenAI may rate-limit you. Add a Wait node between heavy API calls if needed.
